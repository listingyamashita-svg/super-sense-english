# 超感覚英語 - ナオト版 PWA v1

## 使い方
このフォルダを HTTPS で配信できる静的ホスティング（Netlify / Vercel / GitHub Pages 等）にアップロードしてください。

### iPhone
1. Safariで公開URLを開く
2. 共有ボタンをタップ
3. 「ホーム画面に追加」
4. 以後はホーム画面のアイコンから起動

## 収録機能
- 3分トレーニング
- 17コアイメージLesson
- セブ生活50フレーズ（日本語意味付き）
- フラッシュカード
- 4択クイズ
- 英文読み上げ（端末のSpeech Synthesis）
- 学習履歴・連続日数・苦手ランキング（localStorage）
- オフラインキャッシュ（Service Worker）

## 注意
学習履歴は端末内に保存されます。別端末への同期機能はv1にはありません。
